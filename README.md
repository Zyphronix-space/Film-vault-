# FilmVault

A movie and TV series showcase website built with HTML, CSS, and JavaScript —
animated posters, genre browsing, and a personal watchlist.

## Pages
- `index.html` — home/showcase page
- `genre.html` — browse by genre
- `watchlist.html` — personal watchlist

## Running it
Static site — just open `index.html` in a browser, or serve the folder with
any static file server.
